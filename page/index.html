qoder-ssh

管理 SSH 服务器：检测连通性、一键配置 qoderclicn 指向本机 magpie 网关。

部署目标

这里配置远端 ~/.qoder-cn/settings.json 里的网关地址与 key。 远端访问不到内网 IP 时，填隧道对端（如 http://127.0.0.1:23425）。

本机的 mgw provider 由独立的 magpie-gateway 插件提供，不在这里配置。

服务器

添加服务器

状态每 20 秒自动刷新一次（后端探测）。密码存在 magpie 配置目录下 qoder-ssh-secrets.json，权限 600，不会写进 plugins.json。

隧道

在这台机器上建一条 ssh -R：远端 127.0.0.1:23425 → 本机 127.0.0.1:3426（magpie 网关）。远端服务器据此访问模型，不依赖 Win11。

运行日志

隧道脚本用 python gateway_bridge.py --log-file gw.log 启动，日志才会落盘到这里。 本机可填绝对路径；不填则自动查找。

教程：命令安装 qoderclicn 最新版

下面是在 SSH 服务器上手动安装的完整步骤。页面上的「配置 qoderclicn」按钮做的就是这些事。

  1. 确认有 curl 和 python3 
    curl --version | head -1
python3 --version
  2. 装官方安装脚本（自动选 amd64/arm64 原生二进制，不需要 Node.js） 
    curl -fsSL https://static.qoder.com.cn/qoder-cli-cn/install.sh | bash

    升级到最新版加 --force： curl -fsSL https://static.qoder.com.cn/qoder-cli-cn/install.sh | bash -s -- --force； 已装过的也可以 qodercn update。

  3. 验证安装 
    export PATH="$HOME/.local/bin:$PATH"
qoderclicn --version   # 或 qodercn --version
  4. 写入 magpie provider（把地址换成你的网关，远端访问不到内网时用隧道地址） 
    python3 - <<'PY'
import json, os
p = os.path.expanduser("~/.qoder-cn/settings.json")
os.makedirs(os.path.dirname(p), exist_ok=True)
d = json.load(open(p)) if os.path.exists(p) else {}
d.setdefault("providers", {})["magpie"] = {
    "type": "openai-compatible", "protocol": "openai", "authType": "bearer",
    "baseUrl": "http://127.0.0.1:23425/v1",
    "apiKey": "sk-magpie-key-…",
    "displayName": "magpie",
}
d.setdefault("ui", {})["language"] = "zh-CN"
json.dump(d, open(p, "w"), ensure_ascii=False, indent=2)
print("WROTE", p)
PY
  5. 验证能用 
    qoderclicn --list-models
qoderclicn -p --model "magpie/<模型>" "只回复两个字：通了"

关于隧道：如果远端是公网机、访问不到网关的内网地址，需要先建一条隧道 （如 gateway_bridge.py，把远端 23425 转到网关），上面第 4 步的 baseUrl 才填 http://127.0.0.1:23425/v1。

说明

  • 已连网关：本机 magpie 的 mgw provider，模型名 mgw/<模型>。
  • 一键配置会在远端执行：装 qoderclicn（需远端有 npm）→ 写 ~/.qoder-cn/settings.json 指向网关地址。
  • 隧道不在这个插件里：远端要能访问网关地址，仍需 gateway_bridge.py 之类的通道。
